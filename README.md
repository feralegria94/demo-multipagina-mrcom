# Demo Multi-Página — Palafito del Sur

Demo de sitio multi-página para alojamiento en Dalcahue, Chiloé.

**Proyecto:** [Palafito del Sur](https://feralegria94.github.io/demo-multipagina-mrcom/)

## Qué es

Sitio con varias páginas: inicio, cabañas, servicios, galería y contacto. Ejemplo de estructura navegable para clientes que necesitan más de una sección.

## Estructura

- `index.html` — Inicio
- `cabanas.html` — Cabañas
- `servicios.html` — Servicios
- `galeria.html` — Galería
- `contacto.html` — Contacto

## Stack

- HTML5 / CSS3 / JavaScript vanilla
- Responsive (mobile-first)
